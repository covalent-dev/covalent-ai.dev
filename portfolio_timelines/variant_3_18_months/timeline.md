# Portfolio Timeline: Variant 3 (18 Months)

## Theme: The AI Craftsman - Scaling Systems, Building Communities

**Narrative:** An 18-month deep-dive into building scalable, resilient AI systems and establishing a presence in the open-source community. This timeline demonstrates a commitment to not just technical excellence, but also to collaboration and knowledge sharing.

### Month 1-12: (As per Variant 2)

*   **Focus:** Core fundamentals, RAG, fine-tuning, production deployment with Terraform.
*   **Projects:** Agentic career automation, fine-tuned models, reproducible AI stack.
*   **Portfolio Evidence:** Live apps, GitHub repos, blog posts, Hugging Face spaces.

### Month 13-15: Kubernetes and Open Source

*   **Focus:** Container orchestration with Kubernetes, and making a meaningful contribution to an open-source project.
*   **Projects:**
    *   **"Kube-Agent":** Migrate the "Agentic Career Automation Platform" from Variant 2 to run on a Kubernetes cluster (e.g., EKS, or a local k3s cluster).
    *   **Open Documentation Agent:** Create a new open-source project: a RAG-based agent that can answer questions about any GitHub repository's documentation.
    *   **First OSS Contribution:** Make a small but meaningful contribution to a popular AI/ML open-source library (e.g., fixing a bug, improving documentation, adding an example notebook).
*   **Portfolio Evidence:**
    *   Public GitHub repo for "Kube-Agent" with Kubernetes manifests.
    *   Public GitHub repo for the "Open Documentation Agent".
    *   Link to the pull request for the OSS contribution.
    *   Blog post: "Why I Migrated My AI App from Docker Compose to Kubernetes."

### Month 16-18: Advanced Architecture and Community Building

*   **Focus:** Multi-account AWS architecture, advanced deployment patterns, and growing an open-source community.
*   **Projects:**
    *   **Multi-Account AWS Setup:** Refactor the Terraform stack to support multiple AWS accounts (e.g., for dev, staging, and prod environments).
    *   **Canary Deployments:** Implement a canary deployment strategy for the "Open Documentation Agent".
    *   **Grow the Community:** Actively maintain the "Open Documentation Agent" project, respond to issues, review pull requests, and build a small community of users.
*   **Portfolio Evidence:**
    *   Public GitHub repo with the multi-account Terraform setup.
    *   Blog post: "Architecting a Multi-Account AWS Environment for AI."
    *   The "Open Documentation Agent" GitHub repo with evidence of community engagement (e.g., issues, PRs, a Discord server).
    *   A personal website/portfolio that ties all the projects and blog posts together.
