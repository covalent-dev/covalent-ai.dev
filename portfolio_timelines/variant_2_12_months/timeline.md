# Portfolio Timeline: Variant 2 (12 Months)

## Theme: The AI Journeyman - From Fundamentals to Production

**Narrative:** A 12-month journey that builds on a solid 6-month foundation, focusing on production-grade systems, fine-tuning, and infrastructure-as-code. This timeline demonstrates the ability to not just build AI, but to deploy and maintain it.

### Month 1-6: (As per Variant 1)

*   **Focus:** Core AI/ML foundations, RAG, Docker, and basic automation.
*   **Projects:** Personal RAG agent, agentic data processing, etc.
*   **Portfolio Evidence:** Live apps, GitHub repos, blog posts.

### Month 7-9: Fine-Tuning and MLOps

*   **Focus:** Fine-tuning smaller, open-source LLMs (e.g., Llama 3.1, Gemma2), and building a reproducible MLOps stack.
*   **Projects:**
    *   **Domain-Specific Fine-Tuning:** Fine-tune a model on a niche dataset (e.g., financial news, medical research papers) and demonstrate improved performance on a specific task.
    *   **Terraform for AI:** Create a Terraform module that deploys a complete AI stack (e.g., ECS/Fargate, RDS, S3 bucket for models).
    *   **CI/CD Pipeline:** A GitHub Actions workflow that automatically tests, builds, and deploys a simple AI application (e.g., a FastAPI backend for the fine-tuned model).
*   **Portfolio Evidence:**
    *   Hugging Face space with the fine-tuned model and a demo.
    *   Public GitHub repo with the Terraform module.
    *   Blog post: "How I Fine-Tuned Llama 3.1 for Financial News Analysis."
    *   Screenshots/GIFs of the CI/CD pipeline in action.

### Month 10-12: Advanced Systems and Scale

*   **Focus:** Multi-agent systems, advanced monitoring, and building for scale.
*   **Projects:**
    *   **Agentic Career Automation Platform:** An autonomous system that:
        1.  Scrapes job postings.
        2.  Uses a fine-tuned model to rank them based on a personal profile.
        3.  Generates draft cover letters.
        4.  Tracks applications in a database.
    *   **Advanced Monitoring:** Integrate the career automation platform with a more advanced monitoring stack (e.g., Prometheus with custom exporters, Grafana with alerting).
    *   **Blue/Green Deployments:** Implement a blue/green deployment strategy for the career automation platform using Terraform and GitHub Actions.
*   **Portfolio Evidence:**
    *   Live demo of the career automation platform.
    *   Public GitHub repo with the full, reproducible stack.
    *   Blog post: "Building an Autonomous Career Agent with LangChain and Terraform."
    *   Architectural diagram of the system.
